# Web Content Authoring Testbed

This hidden testbed owns browser Worker-conversion, cancellation, persistence, quota, migration, export, and deterministic parity proving surfaces.

Visible scenes must use public named `aero-*` components. Provider responses, downloaded archives, audio, generated packages, IndexedDB dumps, installed dependencies, and generated symlinks are local state and must not be committed.

Create `.testbed/node_modules/@aerobeat/web-content-authoring` with `npm run testbed:link-self`. Add sibling packages only through declared public package boundaries.
